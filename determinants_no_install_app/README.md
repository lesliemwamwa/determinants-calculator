# Determinants Calculator - No Install Version

This version runs without installing Flask or any packages.

## How to Run

1. Extract the ZIP file.
2. Open the folder.
3. Right-click blank space.
4. Click "Open in Terminal".
5. Type:

```bash
py app.py
```

6. Open:

```text
http://127.0.0.1:5000
```

## Note

This version is made so the calculator can run even when Flask installation does not work on the computer.
The determinant algorithm is still manually implemented using recursive cofactor expansion.
